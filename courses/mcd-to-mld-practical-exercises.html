Remise des comptes rendus via GitHub Classroom

Les comptes rendus des travaux pratiques doivent être rendus via GitHub Classroom. Cette plateforme permet de gérer les dépôts Git pour chaque exercice et facilite la correction et le suivi des travaux.

🔗 Accéder à GitHub Classroom

Comment se connecter et lier votre compte GitHub

Pour accéder aux exercices et rendre vos travaux, vous devez d'abord vous connecter à GitHub Classroom et lier votre compte GitHub :

  1. Créer un compte GitHub : Si vous n'avez pas encore de compte GitHub, créez-en un sur github.com (gratuit pour les étudiants).
  2. Accéder à GitHub Classroom : Cliquez sur le lien ci-dessus pour accéder à la classe "Base de données - Licence 1 Informatique".
  3. Se connecter avec GitHub : Sur la page GitHub Classroom, cliquez sur "Sign in to GitHub" et autorisez GitHub Classroom à accéder à votre compte.
  4. Lier votre compte dans le Classroom Roster :
    • Une fois connecté, vous verrez la liste des étudiants (Classroom Roster)
    • Recherchez votre nom dans la liste
    • Cliquez sur votre nom pour le sélectionner
    • Confirmez que c'est bien votre compte GitHub qui est associé
  5. Accepter les exercices : Une fois votre compte lié, vous pourrez accepter les exercices (assignments) qui vous seront proposés. Chaque exercice créera automatiquement un dépôt Git privé dans votre compte GitHub.

Rendre votre travail

Pour chaque exercice :

  • Un dépôt Git privé sera créé automatiquement dans votre compte GitHub
  • Clonez ce dépôt sur votre machine locale
  • Ajoutez vos fichiers de compte rendu (schémas, documentation, etc.)
  • Commitez et poussez vos modifications vers GitHub
  • Le dépôt sera automatiquement visible par l'enseignant pour correction

Note importante : Assurez-vous de bien lier votre compte GitHub à votre nom dans le Classroom Roster avant de commencer les exercices. Si vous rencontrez des difficultés, contactez l'enseignant.
